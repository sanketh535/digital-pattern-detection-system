DIGITAL PATTERN DETECTION SYSTEM USING SEQUENTIAL LOGIC (1011)

PROJECT OVERVIEW

This project involves the design and implementation of a digital pattern detection system using sequential logic circuits. The system is designed to detect the assigned 4-bit binary sequence 1011.

The complete system consists of three main sections:

1. Random Pattern Generator – Generates 4-bit binary patterns.
2. PISO Shift Register – Loads parallel data and converts it into a serial data stream.
3. FSM Pattern Detector – Detects the binary sequence 1011 from the incoming serial data.

The three sections are integrated using a common clock signal to perform sequential pattern detection.
